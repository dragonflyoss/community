# Community Roles

This directory contains information about the various roles and membership levels within the Dragonfly community. Our community follows a structured approach to governance and participation, with different levels of responsibility and access.

> **Note:** The personnel roster lists in this repository are being migrated to [dragonflyoss/.project](https://github.com/dragonflyoss/.project). The roster lists in this repository will be removed and officially migrated to [dragonflyoss/.project](https://github.com/dragonflyoss/.project) before January 1, 2027.

## Members

You can find the list of all members in the [Members.md](Members.md).

## Approvers

You can find the list of all approvers in the [Approvers.md](Approvers.md).

## Maintainers

You can find the list of all maintainers in the [Maintainers.md](Maintainers.md). The canonical maintainer roster for CNCF metadata and automation is maintained in [dragonflyoss/.project](https://github.com/dragonflyoss/.project/blob/main/maintainers.yaml) and must be kept in sync with [Maintainers.md](Maintainers.md).

## Security Team

You can find the list of all security team members in the [Security-Team.md](Security-Team.md).

## Subprojects

The community has several subprojects. Once contributors of subprojects pass the proper promotion processes (e.g., becoming a Member, Approver, or Maintainer), their names are uniformly updated and managed in the corresponding roles lists in this directory, rather than being dispersed throughout individual subproject repositories.
